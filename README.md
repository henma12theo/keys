# servicedev

[![Build Status](https://travis-ci.com/user/servicedev.svg?branch=master)](https://travis-ci.com/user/servicedev)

Este repositório contém o código-fonte do livro "servicedev".

This repository contains the source code of the "servicedev" book.

## Requisitos / Requirements

Building requires [sass]:

```bash
$ cargo install sass --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ sass build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ sass test
```
